# Vyron X — consumer application scope

Vyron X is the user-facing chat client. Training, model evaluation, curriculum, trainer review, knowledge curation and developer workspace functions belong in Vibes Quantum or the server operator console.

Vyron retains the minimum runtime required for a working consumer application: chat UI, provider/gateway client, secure session, voice, personal memory, source display, settings, attachments and conversation export. Those are not trainer/admin screens.

Web search is read-only in Vyron. Training commands and app-side content-ingestion helpers are not exposed. Private-memory and legacy-backup import routines remain only to preserve user data compatibility.
